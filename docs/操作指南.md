# iFund 操作指南

> 本地自托管基金持仓规则平台。访问地址：**http://127.0.0.1:8000**（仅限本机）。
> 默认账号 `admin` / `admin123`。服务已常驻（关机重启后自动拉起，无需手动启动）。

## 一、日常使用流程（先看这个）

平台按"规则驱动、低频操作"设计，日常只有三件事：

1. **每天晚上 21:35 后**：系统自动拉取当日净值并评估全部规则。有规则触发时弹出
   macOS 通知，首页"规则触发提醒"卡片和"规则看板"会同步标红。**没通知就不用看。**
2. **规则触发后**：打开「规则看板」→ 展开该基金 → 点"执行"按钮登记（金额/日期可改），
   或线下在支付宝/天天基金操作后回来补登记。登记后该规则置为已执行、不再提醒，
   已用补仓资金自动累加。
3. **每月一次**：在「规则看板」的"估值百分位"列填入各板块估值（天天基金App → 指数估值），
   系统会给出低估/合理/偏高/高估纪律提示（详见原 Excel 的板块估值纪律）。

## 二、各页面功能

### 首页 · 基金管理（/）
- 顶部**「规则触发提醒」卡片**：当前已触发且未执行的规则清单（基金、档位、触发净值、
  建议动作、金额）；无触发时显示"今日无触发"。
- 下方为上游的基金库管理：全量基金名单、高级筛选（夏普/回撤/规模/区间收益等）、
  保存筛选预设、基金详情（净值迷你图、前十大持仓、AI 定性分析）。

### 规则看板（/rules）★ 核心页面
一行一只持仓基金，列：板块 / 成本价 / 最新净值(含净值日期) / 收益率 / 市值 / 盈亏 /
剩余补仓资金(悬停看计划与已用) / 估值百分位 / **状态**。

- **状态**：`持有观察中`（蓝）、`触发补仓第N档`（红）、`触发止盈`（金）、`数据缺失`（橙）。
- **展开行**：该基金 4 条规则（补仓①-10% / ②-20% / ③-30% / 止盈+25%），含触发净值、
  触发金额、动作描述、是否已触发、执行状态。已触发未执行的规则有**「执行」按钮**：
  弹窗确认金额与日期后一键落账（自动写交易记录 + 累加已用补仓资金）。
- **估值百分位列**：点击可直接编辑（每月手工更新一次），悬停显示对应纪律
  （<30% 低估可正常补仓；30-70% 合理严格按档位；70-80% 偏高停止买入；>80% 高估暂停补仓）。
- **「走势」按钮**：打开净值走势弹窗 —— 历史净值曲线 + 成本价实线 + 4 条触发净值虚线
  （补仓红色系、止盈绿色），支持 近3月/6月/1年/3年/全部 区间切换，显示区间涨跌与
  持仓收益。QDII 基金会提示净值滞后 1-2 个交易日属正常。
- 顶部汇总卡片：持仓基金数 / 总市值 / 总浮动盈亏 / 已触发待执行规则数。

### 实盘（/holdings）
上游功能。持仓由"初始快照 + 交易记录"按基金会计原则（份额×净值、移动平均成本）合成。
当前 11 只基金由 Excel 导入为建仓交易。在这里可以：查看合成持仓与盈亏、手工补记
买入/卖出/转仓交易、做再平衡对账（需先配置永续组合目标权重）。

### 镜像基金（/workbench）
上游功能。把筛选条件存成预设、生成"镜像快照"，跟踪每期筛选结果的新增/剔除变化。

### 永续组合（/perpetual）
上游功能。按行业暴露聚类分赛道，每个赛道选代表基金给出目标仓位建议（加码/标配/减码），
供「实盘」页再平衡对账使用。

### 基金经理（/manager）/ 交易日历（/trade_calendar）/ 行业映射（/industry）
上游辅助数据页：基金经理任职史与业绩、A 股交易日历、持仓股票→申万三级行业映射覆盖率。

### 访问令牌（/tokens）
创建个人访问令牌（PAT），用于 MCP / 本机 AI agent 接入平台能力。平时不用管。

## 三、命令行速查（后端目录 ifund/backend 下）

```bash
./venv/bin/python -m cli rules overview     # 全部基金触发状态表
./venv/bin/python -m cli rules alerts       # 已触发待执行规则
./venv/bin/python -m cli rules daily        # 手动执行一次"拉净值+评估+通知"
./venv/bin/python -m cli fetch nav --codes 008163,011949   # 手动补拉净值
./venv/bin/python -m cli import-xlsx run --file <xlsx> --reset   # 重新导入 Excel
./venv/bin/python -m unittest tests.test_rules             # 规则引擎单测
```

## 四、运维

```bash
cd ifund
./service.sh status / restart / stop / logs   # 后端常驻服务（launchd: com.ifund.server）
./daily.sh status / run / logs                # 每日规则任务（launchd: com.ifund.daily-rules）
```

- 后端日志：`ifund/logs/backend.{out,err}.log`；每日任务日志：`~/Library/Logs/ifund/daily-rules.log`。
- 改了后端代码要 `./service.sh restart` 才生效（waitress 无热重载）；
  改了前端代码要 `cd frontend && npm run build`。
- 想热重载调试：`./service.sh stop` → `./start.sh` → 调完 Ctrl-C → `./service.sh start`。

## 五、常见问题

- **QDII（017641 摩根标普500）净值日期比别人晚**：正常，QDII 净值公布滞后 1-2 个交易日。
- **没有盘中实时估值**：天天基金估值接口已被监管下线，平台为"每日净值"模式，
  每晚 21:35 自动更新，不影响低频规则操作。
- **页面数据看起来旧**：浏览器强刷（Cmd+Shift+R）；若净值日期没更新，跑
  `./daily.sh run` 手动拉一次。
- **提醒没弹 macOS 通知**：检查 系统设置 → 通知 里有没有拦截；规则是否已被执行过
  （已执行的规则不再提醒）。
